# G8 固定采样节奏复测：独立数值复核

本复核重新读取三台 H100 的全部 shard，独立构建 worker/visit 中位数矩阵与共享 bootstrap 索引，没有修改冻结分析、原始样本、compiler artifacts 或协议。

## 完整性与基线

- 64 个 context；每 worker 505 个物理条件，其中 439 个原物理条件、66 个同程序 repeat。
- 583 个逻辑行，包含原来的 517 条比较与 66 个 repeat 观测；共 469,650 个正式目标样本。
- 78 个逻辑 U/G0 对照与 78 个逻辑 sham 对照均通过 ±3% 实用等价。actual/B4 别名共享观测，因此各自对应 66 个物理对照，不是 78 台独立 GPU。
- U/G0 点估计范围为 −1.205% 至 +1.650%，全部区间端点位于 −2.440% 至 +2.182%；sham 区间端点位于 −0.548% 至 +0.465%。没有以未通过的控制支持改进。
- U、G0 与 repeat 各 198 个 worker/cell 的 visit 中位数跨度均未超过 3%，最大分别为 2.525%、2.759%、2.918%。这不是对其他程序或其他运行条件的普遍稳定性保证。

## 主要结论与 ABI/pipeline 边界

- vLLM b64 下，vec1 的明显退化保留：s16/d128 为 −46.146%，s32/d128 为 −71.630%；vec4:within 则分别为 +7.264%、+7.235%，均通过双控制门槛。
- s32/d256/b1 的 actual 与 B4 target 从原 +5.843% / +3.803% 变为新 +6.500% [6.363,6.665] / +4.278% [4.139,4.402]；真实 ABI 与 replay 对照仍不能混为一个条件。
- SGLang d64/b1 的 target 在 stage1 中为 −4.961% [−6.647,−3.103]，完整 decode 中为 −2.165% [−2.582,−1.564]。双核时间会稀释 stage1 差异，不能把 stage1 百分比直接用于 decode。
- LN 原固定候选的 merge 收益保留：p256/n1024 vec4:n_first +28.835%，p128/n4096 vec4:n_first +20.109%，p96/n8192 vec4:within +15.263%。相应 full M2048 为 +11.072%、+4.227%、+1.205%，最后一项仍在 3% 以下。

## 主机节奏边界

请求的是最小 1 ms host gap，不是硬实时的精确 1 ms。实际最小 1004.115 µs，cell/worker 中位数的中位数为 1079.235 µs，最大 67.580 ms；全部长尾样本保留，未过滤。八次 GPU 内 prime 到目标迭代之间没有主机提交，提供一致的目标前置执行历史。

完整复算和最终检查分别见 [analysis/analysis.json](analysis/analysis.json)、[validation_final.json](validation_final.json)。本复核不新增 GPU 实验、不重新选模型、不修改旧结果。
