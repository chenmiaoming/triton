# 结果使用边界

本轮支持“固定编译器、H100、所列真实源码入口存在默认布局优化机会”。没有进行历史版本对照，不能据此证明其它算子在全部版本中一直次优，也不把它们称为版本性能回归。

输入覆盖随机有限值、1/8 步进值和符号翻转图案；名为 cancellation 的图案是符号翻转，不是严格的成对抵消压力集。未充分覆盖 NaN/Inf、全部特殊浮点行为和真实模型数据轨迹。

vec2/vec4 在这些训练点上优于 vec1，并不自动证明复杂成本模型胜过简单固定 vec4。这里没有拟合新模型；后续选择策略仍需与 fixed_vec1/2/4/8、原始默认及完整图布局一起对比。各候选的统计区间均是探索性的，不能将事后最小值当作预冻结策略的盲测收益。

原始 Triton U 与 Gluon G0 并非机器码完全等价。正文同时列出 vs U 与 G0→GL，避免把桥接差异全部归为布局收益。原始 dx_fused 保持不变；pipeline 使用 BF16 partial 的实际舍入语义。

最初 24 份训练 NCU 报告的候选在计时前固定；看见计时后又单独冻结了剩余全部候选的 36 份报告，包含无收益对照。这是透明的探索性机制补证，不改变原 41,850 个正式样本。
