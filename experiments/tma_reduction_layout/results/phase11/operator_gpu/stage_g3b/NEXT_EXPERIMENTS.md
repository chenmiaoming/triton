# 接下来最值得补的证据

当前术语应为“默认布局的优化空间 / 布局选择次优”。只有最初存在旧版与新版时间对照的 TMA 案例称为版本性能回归。本轮没有证明其它算子在全部历史版本中一直次优。

## 第一优先：把已观察到的收益与开销拆得更清楚

1. **SGLang vec4 的依赖链与邻接转换**：已有收益和该候选专门的 NCU，但它的 WF、BAR、寄存器均增加。固定数学、分页、tile、warp 与精度，对 PV 布局和邻接 QK/概率布局做小规模因子对照；先验证干预确实改变目标机器码。不能把同时变化的 QK 加载代价当成纯转换代价，也不能把指令数直接加成时间。
2. **LayerNorm 单次加载与两路 FP32 累加的折中**：本轮 vec1 无 SHFL/BAR/WF，却比 vec2/4 慢；请求数增加、sector 数不变。下一轮应保持真实循环次数、活跃值、输出语义，检验访存发射/地址处理与规约依赖长度。旧的 K64 fixture 斜率不直接当作 K1 完整内核代价。
3. **实际活跃并发而非容量 q**：LayerNorm 只有 8/32/64 CTA，本轮容量下降未带来实际占用变化。需要在真实较大 N 或多独立归一化组的实际调用中验证，而不是把同一输入重复成不相关的大 grid。

## 第二优先：落实到实际框架与完整算子

- 对固定 vLLM/SGLang 入口按实际 batch/dispatch 分别 JIT，补 G2 统一 B4 绑定之外的真实专化；保留 U→G0 的桥接差异。计 kernel、完整 attention 和框架层收益，不能只列最好子图。
- LayerNorm 在已固定的原始算法下，记录其占一层 backward 的比例；本轮两个 kernel + 三个 memset 已不是纯子图，但仍不是含框架、前向和优化器的完整训练 step。
- 对从本轮选出的布局作新输入/工作负载上的预冻结确认；当前最小均值属于探索性观察，不能当独立确认或通用选择器效果。

## 第三优先：其余候选先确认“模型真的走这里”

| 候选 | GPU 扩展前必须确认 | 有意义的对照 |
|---|---|---|
| C03 columnwise FP8/MXFP8 | 实际量化 recipe、组方向、尺度编码和消费它的 GEMM；不混同 FP32-scale fixture 与 E8M0 | 完整量化 + 所需后续消费者，按硬件支持分开 |
| C04 fused RMSNorm backward | Liger 实际 block 分支的 dispatch；不能用小 hidden 分支代表所有 LLM hidden | 保留两方向规约、二维 dX 与一维 dγ 输出 |
| C05 Linear/MLP bias gradient | 具体模型确实含 bias，捕获实际 torch.sum/Inductor/CUDA 后端 | 原生成物与同语义 Gluon，不强行制造一个 Triton 默认 |
| C07 Gated DeltaNet | 保留实际 V-first、1 warp 与状态接口；不是已确认跨 warp 问题 | 输出及多步状态一起校验，转换/缓存成本计入 |
| C08 embedding pooling | 实际 embedding 模型是否配置该 pooling，以及实际执行后端 | 保留变长、mask、权重与归并策略，区分算法变化 |

跨 B200/SM120 的迁移仍有价值，但应在这些源码语义、机器码和实际调用边界更清楚后开展；本批未据 H100 结果外推其它架构。
